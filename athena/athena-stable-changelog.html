BB-CalyxOS 1.0

Unofficial CalyxOS port for the BlackBerry KEY2 (Athena) featuring security hardening, performance improvements, OTA updates, SELinux enforcing, and extensive hardware support.

🚀 New in This Release

Kernel

Security Updates

  • Linux kernel upgraded from 4.19.325-cip128 to 4.19.325-cip136.
  • Includes approximately 1,970 upstream bug fixes and security improvements.
Security

Hardening

  • SELinux now runs in Enforcing mode.
  • Correct storage, graphics, modem and thermal labeling.
  • Removed legacy boot logger.
  • System and APEX modules signed using private release keys.
Performance

Boot & Memory

  • First-stage init reduced from 20 seconds to 0.3 seconds.
  • 2 GB LZ4 ZRAM enabled.
  • Optimized memory management.
  • System apps precompiled into ROM.
Multimedia

Video & Thermal

  • Fixes video freezes in apps such as X.
  • Hardware decoder now switches surfaces correctly.
  • Real CPU, GPU, skin and battery temperature reporting.
Audio

Volume Improvements

  • Lower minimum ring and notification volumes.
  • Smoother volume scaling curve.
  • Maximum loudness remains unchanged.
Buttons

Navigation Controls

  • Back, Home and App Switch buttons provide haptic feedback.
  • Long press and shortcut actions configurable.
  • Answer calls with Home button.
OTA Updates

Update System

  • Background OTA downloads supported.
  • Updates delivered from GitHub Releases.
  • Reboot notification automatically triggers installation.
Troubleshooting

Collect Logs

  • New diagnostic report generator.
  • Accessible through BlackBerry Settings.
  • Produces privacy-sanitized logs for bug reporting.

⌨️ Keyboard & Touchpad

  • Speed Key now functions as Ctrl.
  • Alt and Sym keyboard layers restored.
  • IME switcher shortcut works again.
  • Physical keyboard PIN entry works on lockscreen.
  • Touchpad no longer triggers screen taps.
  • Smooth keyboard scrolling with momentum.
  • Quick Settings toggles for touchpad and scrolling.

📱 Hardware Improvements

Camera & Fingerprint

  • Missing fingerprint and camera libraries restored.
  • Faster fingerprint unlock.
  • Dual-tone LED flashlight corrected.
  • Improved biometric haptic feedback.

Connectivity

  • Wi-Fi Calling operational.
  • Carrier APN database restored.
  • NFC tuning restored.
  • Bluetooth AAC codec support.
  • microSD and USB storage detection fixed.

Display & Graphics

  • Updated Adreno SDM660 graphics drivers.
  • Reduced scrolling jank.
  • Improved rendering smoothness in social apps.

🏗 Foundation Work

  • Linux 4.19 kernel support for KEY2 hardware.
  • Updated device and vendor trees.
  • VoLTE and Wi-Fi Calling support.
  • Widevine DRM support.
  • Display, GPS, Bluetooth and camera compatibility improvements.
  • Dedicated BlackBerry Settings application.
  • KEY2 modifications maintained through a clean patch-based workflow.
